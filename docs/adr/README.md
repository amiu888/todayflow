# Architecture Decision Records

We record significant architectural decisions as ADRs, one file each, numbered in
order of adoption. Each ADR follows the template in `0000-template.md`.

Once an ADR is accepted it is immutable; supersede it with a new ADR that references
the old one rather than editing it.
